MPR tools

Mouse
  • Left click/drag – move crosshair
  • Trackpad? Switch Input → Trackpad and see the Trackpad guide
  • Hold Shift – crosshair follows the mouse
  • Ctrl+Alt+drag (or Rotate tool) – rotate the other planes around this view
  • Crop tool – drag the blue box edges
  • Wheel – scroll slices
  • Ctrl+wheel or right drag – zoom · Alt/middle drag – pan
  • R – ruler: click start, click end; drag ends to edit, Del removes the hovered ruler
  • M or ⤢ – maximize / restore view
  • Right drag can be switched to brightness/contrast in the toolbar

    Mouse
    • Trackpad? Switch Input → Trackpad and see the Trackpad guide
    • Axial: wheel = level, drag curve points, dbl-click curve = add / point = remove
    • Panoramic: wheel = slice position buccal/lingual, Alt+wheel = move along the curve, click = jump
    • Cross-sections: wheel = move along the curve
    • Tangential: wheel = rotate 360° (around the selected implant)
    • Implant: drag body = move · drag side outline = diameter (tapered: apical half = apex Ø) · drag apical end = length (click the live value to type it)
    • C / A handles (selected implant): C rotates around the apex, A rotates around the platform
    • Esc deselect / cancel · Del delete implant · double-click a name in the list to rename
    • Cross-sections follow the selected implant when it moves
    • Ctrl+wheel or right drag zoom · Shift/Alt/middle drag pan · M maximize · R ruler
