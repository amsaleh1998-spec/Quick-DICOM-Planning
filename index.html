MPR tools

Mouse
  • Left click/drag – move crosshair
  • Ctrl+Alt+drag (or Rotate tool) – rotate the other planes around this view
  • Crop tool – drag the blue box edges
  • Wheel – scroll slices
  • Ctrl+wheel – zoom · Shift/middle drag – pan
  • Right drag – window / level

Panoramic curve

Implants

    Mouse
    • Axial: wheel = level, drag curve points, dbl-click curve = add / point = remove
    • Panoramic / cross-sections: wheel = move along the curve, click = jump
    • Tangential: wheel = rotate 360° (around the selected implant)
    • Implant: drag body = move, drag near an end = tilt
    • Esc deselect / cancel · Del delete implant
    • Ctrl+wheel zoom · Shift/middle drag pan · Right drag W/L
